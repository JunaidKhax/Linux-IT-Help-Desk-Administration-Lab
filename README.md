# Linux IT Help Desk Administration Lab

## Linux IT Support & System Administration using Ubuntu

This project demonstrates hands-on Linux IT Support and System Administration practice using Ubuntu. The objective was to understand common Linux CLI operations, file management, log analysis, permissions, backups, and basic troubleshooting.

## Key Objectives

- Linux file and directory management
- Help Desk ticket management
- User information management
- Log analysis and error searching
- File and directory permissions
- Administrative access using sudo
- File backup and organization
- Troubleshooting permission issues

## Tools Used

- Ubuntu Linux
- Linux Terminal / CLI
- Common Linux commands
- Linux file permissions

## Implementation Steps

1. Created a Help Desk directory structure for tickets, users, logs, backups, and resolved tickets
2. Navigated the Linux file system using `pwd`, `ls`, and `cd`
3. Created files using `touch`
4. Created and updated ticket information using `echo`
5. Read ticket and system information using `cat`
6. Searched logs for errors and warnings using `grep`
7. Copied important files to create backups using `cp`
8. Moved completed tickets using `mv`
9. Checked Linux file permissions using `ls -l`
10. Changed file permissions using `chmod`
11. Used `sudo` for administrative operations
12. Troubleshot and resolved a simulated file permission issue
